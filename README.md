# 보조금 부정수급 조사 데스크

보조금 부정수급 의심 사례를 **조사 → 진단(위험도 산정) → 신고서 작성 → 포털 제출**까지 한 흐름으로
지원하는 단일 파일 웹 도구입니다. `index.html`을 브라우저로 열면 바로 동작합니다(서버·설치 불필요,
데이터는 브라우저 localStorage에만 저장).

## 기능

**핵심: 공시된 실제 보조사업 정산 내역을 직접 분석해 부정 확률 순위를 냅니다.**

0. **정산 데이터 분석** — 보조금통합포털·e나라도움·공공데이터포털에서 받은 **실제 집행·정산 내역**
   (CSV/TSV/JSON)을 올리면 회계부정 정량 지표 **15종**으로 사업별 부정 확률을 계산해 정렬.
   룰마다 탐지 수치·해당 거래 목록·확보할 증빙을 제시하고, CSV로 내보내거나 바로 신고 진단으로 넘길 수 있습니다.
   데이터는 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.
1. **실제 사례 DB (139건)** — 정부 점검 발표·감사 결과·법원 판결·기관 환수 처분 등 **공개된 실제
   적발 사례**를 신고 구분(8종)별로 정리하고, 부정 확률·예상 보상금·부정수급액·연도 기준으로 정렬.
   수법 키워드 검색과 확인 단계(판결/감사/기관/통계) 필터 제공. 사례를 클릭하면 해당 수법의 탐지
   로직이 자동 체크된 상태로 진단 탭으로 이관됩니다.
2. **신고 가이드·포털 취합** — 청렴포털, 1398 통합신고센터, 보조금통합포털(보조금24), e나라도움,
   복지로(129), 고용노동부(1350), 감사원, 국민신문고 등 신고·확인 포털을 대상·특징별로 정리.
   보상금(최대 30억, 구간별 4~30%)·포상금(최대 5억)·제재부가금(최대 5배) 및 신고 요건 안내.
3. **사례 진단** — 탐지 로직 14종의 징후 체크 + 로직별 필요 증빙의 확보 상태(미확보/확보 가능/확보)를 입력.
4. **위험도 순위** — 저장된 사례를 부정수급 확률이 높은 순으로 정렬. 미비사항(부족한 필수 증빙)과
   증빙 준비도(신고 성공 가능성 지표)를 함께 표시.
5. **신고서 자동 생성** — 진단 결과로 신고서 초안(신고 취지·유형별 근거 법령·증거 목록)을 자동 작성,
   복사/txt 저장 후 포털 신고 양식에 붙여넣기. *정부 포털은 본인인증이 필요해 외부 프로그램의
   자동 제출을 허용하지 않으므로, "자동 생성 + 원클릭 이동" 방식이 실질적 최선입니다.*

## 정산 데이터 분석 — 정량 탐지 지표 15종

실제 집행 내역(거래처·계약방법·금액·일자·비목)에서 계산되는 지표입니다.

| # | 지표 | 가중치 | 탐지 근거 |
|---|------|:---:|-----------|
| 1 | 쪼개기 계약 (수의계약 한도 회피) | 10 | 한도 2천만원의 85~100% 구간 계약이 동일 거래처에 반복 |
| 2 | 특수관계 의심 거래 | 10 | 보조사업자와 거래처의 사업자번호·대표자명 일치 |
| 3 | 특정 업체 몰아주기 | 9 | 상위 거래처 점유율·허핀달지수(HHI) |
| 4 | 중복 결제 | 9 | 동일 거래처·금액·일자 반복 |
| 5 | 벤포드 법칙 이탈 | 8 | 선두자리 분포 MAD(Nigrini 기준 0.015 초과), 표본 크기로 감쇠 |
| 6 | 인건비 비중 이상 | 8 | 인건비 비중·1인당 금액 이상치 |
| 7 | 음수·취소 금액 | 8 | 세금계산서 취소 후 미환입 흔적 |
| 8 | 수의계약 비율 과다 | 7 | 경쟁입찰 없이 집행된 비중 |
| 9 | 라운드 넘버 편중 | 7 | 10만·100만원 단위 정액 비율 |
| 10 | 동일 금액 반복 집행 | 7 | 고액 동일 금액 4회 이상 반복 |
| 11 | 단일 거래 전용 거래처 | 7 | 1회만 등장하는 고액 거래처(페이퍼컴퍼니 지표) |
| 12 | 사업 종료 직전 집행 쏠림 | 6 | 기간 마지막 15%에 집행 집중 |
| 13 | 집행률 100% 정확 일치·초과 | 6 | 잔액 0원 정산 맞추기 |
| 14 | 증빙 미기재·간이증빙 | 6 | 증빙 유형 공란·간이 영수증 비율 |
| 15 | 주말·공휴일 집행 | 5 | 일자 소급 작성 지표 |

**부정 확률** = Σ(지표 가중치 × 지표 점수) ÷ 전체 가중치 × 스케일 × 표본 신뢰도.
거래 건수가 적으면 신뢰도로 감쇠합니다.

**검증 결과** — 로그정규 분포·평일 집행·다수 거래처의 정상 대조군 6개 사업은 평균 **5.7**,
쪼개기·몰아주기·특수관계가 심어진 사업은 **99**로 분리됩니다.

## 데이터 수집: `fetch-bojo.mjs`

```bash
# 공공데이터포털 OpenAPI (인증키 필요)
node fetch-bojo.mjs api --key=<serviceKey> --pages=20 --out=data.json

# 포털에서 내려받은 CSV/TSV/XLSX 변환
node fetch-bojo.mjs file 집행현황.csv --out=data.json
```

컬럼명은 별칭 사전으로 자동 인식합니다(보조사업명·보조사업자·거래처·계약방법·집행액·집행일자 등).
생성된 `data.json`을 앱의 **정산 데이터 분석** 탭에 올리면 순위가 나옵니다.

1억 이하 30% · 1억~5억 20% · 5억~20억 14% · 20억~40억 8% · 40억 초과 4%, 건별 상한 30억.
(예: 1억 → 3천만 원, 40억 → 4.8억 원)

## 탐지 로직 14종

**산정식**
- 위험도 = Σ(가중치 × 체크된 징후 비율) ÷ Σ(전체 가중치) × 100
- 증빙 준비도 = 발동 로직의 필요 증빙 확보 상태 평균(확보 1.0 / 확보 가능 0.5 / 미확보 0)
- 우선순위 = 위험도 × 0.7 + 증빙 준비도 × 0.3 (내림차순 정렬)

## 조사 결과: 성공률이 높은 신고 방식

- **실명(기명) 신고가 원칙** — 공익신고자보호법 §8은 익명 신고를 인정하지 않음.
  신원 노출이 부담되면 **변호사 비실명 대리신고**(국민권익위원회만 접수) 이용.
- **구체적 증거가 성패를 좌우** — 계좌내역·계약서·세금계산서 등 객관 증빙 첨부 시 조사 착수율↑.
  육하원칙으로 정리된 신고서 필수.
- **관할 선택** — 국고보조금은 e나라도움/보조금통합포털, 복지급여는 복지로(129),
  고용지원금은 고용부(1350), 불명확하면 청렴포털·1398(통합) 또는 국민신문고.
- **신고자 보호** — 신분보장·신변보호·비밀보장, 책임감면 제도 법정화.
- **유인** — 보상금 최대 30억(보상대상가액 구간별 4~30%), 포상금 최대 5억,
  부정이익은 공공재정환수법상 전액 환수 + 제재부가금(허위 500% / 과다 300% / 목적외 200%).

## 주의

허위 사실 신고는 무고죄·명예훼손 책임이 따를 수 있습니다. 이 도구의 점수는 조사 우선순위를 위한
참고 지표이며, 부정수급 여부의 최종 판단은 조사·수사기관의 권한입니다. 법률 자문이 아닙니다.
